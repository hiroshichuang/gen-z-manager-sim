# 他明天還會來嗎？

一款訊息遊戲。你是行銷主管，對面是整頓職場的 Z 世代員工。
他丟一句，你挑一句回。**留任意願掉到 0，他就送出離職單，你就輸了。**

支援**繁體中文、English、日本語**，可在開始畫面切換語言。三種語言的題庫與結局內容**完全對等**。

▶ **[開始玩](https://hiroshichuang.github.io/gen-z-manager-sim/)**

---

## 玩法

- 起始留任意願 **55**，顯示在手機狀態列的電池上
- 每題四個回覆，外加一個 **「已讀，不回」**
- 有些題目**回什麼都扣分**——那時候已讀才是對的
- 踩到**地雷**當場出局，整局有**一次收回訊息**的機會（−8）
- 你壓得越穩，他越願意繼續聊，題目越多（8～12 題）

## 六種結局

| 結局 | 條件 |
|---|---|
| BLOCKED | 你對他發起視訊 |
| GAME OVER | 留任意願中途歸零 |
| BAD END | 撐完但 1–39 |
| NORMAL END | 40–64 |
| GOOD END | 65–84 |
| BEST END | 85–100 |

每種結局有 10 句他的 murmur，隨機出現。

## 手機上還能做什麼

左上返回鍵能看收件匣、點頭像有限時動態（18 則隨機抽 3～5）、點 ID 看得到他的個人檔案。
電話跟視訊也能按——後果自負。

## 題庫

22 個類別、67 個情境、264 個選項。
每局隨機抽 11 個類別各一題、順序打亂，所以**每次玩都不一樣**。

情境包含：臨時加班、加班費、下班訊息、聚餐團康、職場言語、JD 範圍、薪資、
遠端彈性、職涯路徑、回饋方式、請假、文化畫餅、會議文化、輩分老鳥、社群隱私、
自費學習、出差交通、DEI 與不當玩笑、離職前兆、裁員與 AI、牢騷、情緒勒索。

## 改文案

**單一 `index.html`，零外部依賴**——直接雙擊就能玩，不需要架伺服器。

- 中文題庫：搜尋 `const BANK = [`，每個類別上面都有註解標示
- 中文結局 murmur：搜尋 `const MURMUR`
- 限時動態：搜尋 `STORY_POOL`
- 英日語系內容：搜尋 `window.GAME_I18N`，各語系底下的 `bank` / `boss` / `murmur` / `stories`
